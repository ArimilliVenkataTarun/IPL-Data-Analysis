# IPL Data Analysis Project

## Overview

This project analyzes Indian Premier League (IPL) cricket data using Python and Data Analytics techniques. The project explores match statistics, team performance, player performance, toss impact, venue analysis, and data visualization using IPL datasets.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Dataset Used

The project uses:

* `matches.csv`
* `deliveries.csv`

Dataset Source:

* Kaggle IPL Dataset

---

## Features

* Most successful IPL teams analysis
* Toss winner and toss decision analysis
* Player of the Match analysis
* Top run scorers analysis
* Top wicket takers analysis
* Venue-wise match analysis
* Season-wise trends
* Data visualization using charts and graphs

* Mumbai Indians and Chennai Super Kings are among the most successful IPL teams.
* Toss decisions influence match outcomes in several conditions.
* Top players consistently dominate batting and bowling statistics.
